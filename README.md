# Java Coding Practice

This repository documents my progress in Java programming, data structures, algorithms, and technical interview preparation.

I use this repository to practice problem-solving, understand common programming patterns, and improve my ability to write clear and efficient Java code.

## Goals

- Strengthen Java fundamentals and object-oriented programming.
- Develop a strong understanding of data structures and algorithms.
- Practice recursion, arrays, strings, searching, and sorting.
- Improve problem-solving and debugging skills.
- Learn to analyze time and space complexity.
- Prepare for software engineering internships and technical interviews.

## Topics

| Topic | Description |
|---|---|
| Recursion | Base cases, recursive calls, and call stack |
| Arrays | Traversal, searching, and manipulation |
| Strings | Character processing and string problems |
| ArrayLists | Dynamic arrays and collection operations |
| HashMaps and HashSets | Key-value storage and efficient lookups |
| Two Pointers | Solving problems using multiple indexes |
| Searching and Sorting | Common searching and sorting algorithms |
| Linked Lists | Nodes, references, and traversal |
| Stacks and Queues | Linear data structures |
| Trees | Tree traversal and recursion |
| Graphs | Graph representation and traversal |
| Backtracking | Exploring possible solutions |
| Dynamic Programming | Recognizing and solving overlapping subproblems |

## Repository Structure

Problems are organized by topic. Each solution includes an explanation of the approach, pseudocode when useful, Java implementation, and complexity analysis.

## My Approach

For each problem, I aim to:

1. Understand the problem and identify the requirements.
2. Explain the approach in plain English.
3. Write pseudocode before implementing when helpful.
4. Develop and test a Java solution.
5. Analyze time and space complexity.
6. Record mistakes and lessons learned.

## Progress

This repository is an ongoing record of my learning. I distinguish between problems solved independently, problems solved with hints, and problems that I have reviewed.

I prioritize understanding and consistent improvement over the number of problems completed.
